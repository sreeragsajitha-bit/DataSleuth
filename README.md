# DataSleuth

A local AI-powered data analysis platform.

## Vision

DataSleuth aims to help users explore datasets,
discover patterns, detect anomalies and generate
data-driven insights using local AI.

## Core Features

- Automated data profiling
- Data cleaning
- Statistical analysis
- Data visualization
- Anomaly detection
- Machine learning
- Natural language data interaction
- Automated reporting

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- DuckDB
- Streamlit
- FastAPI
- Local LLMs
